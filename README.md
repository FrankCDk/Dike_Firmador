# OBJETIVO

El objetivo del proyecto es generar un archivo JSON firmado y encriptado que funciona con una llave publica (para la lectura de la aplicación) y una llave privada para el firmado de la aplicación.

## Caracteristicas

- Generar llave publica y privada para lectura y firmado, respectivamente.
- Generación de archivo JSON firmado.
- Archivo JSON inmutable y encriptado.
